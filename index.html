Общий алгоритм выполнения билета и архитектура WPF-приложения

Полное руководство от создания БД в SSMS до запуска минималистичного приложения в Visual Studio

Что требуется реализовать по билету:
  • База данных (MS SQL Server): две связанные таблицы с первичными (PRIMARY KEY) и внешними (FOREIGN KEY) ключами, а также полем ImagePath для хранения относительного пути к изображению.
  • Главное окно (MainWindow): вывод логотипа в шапке, вывод записей главной таблицы через ListView с картинками, автоматическая подстановка заглушки picture.png при отсутствии фото, поиск и сортировка.
  • Окно табличных данных (TableWindow): вывод обеих таблиц в DataGrid (на двух вкладках TabControl), добавление, редактирование и удаление записей через Entity Framework 6.

Создание базы данных и диаграммы связей в MS SQL Server (SSMS)

Пункт 1 билета — проектирование таблиц, ключей PK/FK и наполнение тестовыми записями

  1. Откройте SQL Server Management Studio (SSMS) и подключитесь к локальному серверу (Проверка подлинности Windows).
  2. Нажмите кнопку Создать запрос (New Query) на верхней панели.
  3. Скопируйте готовый SQL-скрипт ниже (create_database.sql), вставьте в окно запроса и нажмите Выполнить (F5).
  4. Скрипт автоматически создаст базу данных SupplyGoodsDB, две связанные таблицы, поле ImagePath и заполнит их тестовыми записями.
  5. Построение диаграммы БД (если требуется показать схему): в «Обозревателе объектов» нажмите ПКМ по «Базы данных» → Обновить → раскройте вашу БД → ПКМ по папке Диаграммы баз данных (Database Diagrams) → Создать диаграмму базы данных → выделите обе таблицы и нажмите Добавить.

Создание проекта WPF (.NET Framework), папок и добавление ресурсов

Подготовка структуры решения Visual Studio и графических файлов для главного окна

  1. Откройте Visual Studio → Создание проекта → выберите шаблон Приложение WPF (.NET Framework) на языке C# (обязательно с пометкой .NET Framework, так как визуальный дизайнер EDMX работает только в нём).
  2. Укажите имя проекта: Ticket01_SupplyGoods и нажмите Создать.
  3. В Обозревателе решений (справа) создайте 3 папки (ПКМ по проекту → Добавить → Создать папку): classes, Windows и Resources.
  4. Скачайте ниже logo.png и picture.png, перетащите их в папку Resources в Обозревателе решений, выделите оба файла, нажмите F4 (Свойства) и установите Действие при сборке (Build Action) = Resource.
  5. Выполните сборку (Ctrl + Shift + B), откройте папку проекта в Проводнике → перейдите в bin\Debug → создайте папку images и скопируйте туда 4 картинки (item1.png … item4.png).
