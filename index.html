Построение и привязка мнемосхемы

1. Размещение элементов из Палитры:
  • • Текст и Часы: из раздела Окна / Управление добавляем элемент Текст (ПКМ → Свойства → Текст → выравнивание по центру, пишем «Схема Фамилия И.О.») и элемент Часы.
  • • 12 Цилиндров: из раздела Объёмные элементы перетаскиваем 12 цилиндров (Блок 10 делаем шире по горизонтали).
  • • Трубопроводы: из раздела Объёмные элементы добавляем Трубопровод. Для поворота: ПКМ → Свойства → Параметры → Контрольные точки, выделяем вторую точку {0, 90}, вводим координаты и жмем Присвоить → ОК:

2. Привязка слайдеров, цифр и заливки:
  • • Слайдеры процентов: перетащите команды (8%, 9%, 10%, 11%, 12%) на мнемосхему ПРАВОЙ кнопкой мыши и в меню выберите Слайдер.
  • • Индикаторы значений: перетащите значения и расчеты к каждому из 12 цилиндров. Чтобы убрать лишнее название перед цифрами (например, 300-350кг 0.00 кг), откройте ПКМ → Свойства → Значение и очистите поле «Текст до значения».
  • • Анимация заливки цилиндров: выделите цилиндр → внизу справа откройте вкладку Свойства → кнопка входов (синяя стрелка) → раздел Заливка → перетащите нужный расчет/значение из дерева на строки «Процент заливки» и «Цвет заливки».

Почему в формулах появляются нижние подчеркивания?

MasterSCADA не допускает имена переменных, начинающиеся с цифры или содержащие дефисы, пробелы и знак %. При перетаскивании элемента в таблицу формул система автоматически преобразует:

110-300кг → _110_300кг
8% → _8_
с 3 на 5 → с_3_на_5

Правило: Никогда не вписывайте имена переменных руками! Перетащите элемент в таблицу внизу вкладки «Формула» и дважды кликните по строке в таблице.

➔

Команда vs Значение vs Расчет

Для каждого элемента дерева важно выбрать правильный тип объекта:

  • Значение (⇄): Только для входных датчиков (110-300кг, 300-350кг). Настраивается во вкладке Опрос → Имитация → Шум.
  • Команда (➔): Только для процентов (8%..12%). Настраивается во вкладке Опрос выхода → Значение до опроса, чтобы имитация не перезаписывала число.
  • Расчет (±×÷): Для всех остальных узлов (3, 4, 6, 8, 9, 10, 11) и стрелок остатка (с 3 на 5 и т.д.).
0.00

Лишний текст перед значением на мнемосхеме

При перетаскивании элемента на мнемосхему MasterSCADA по умолчанию подписывает его именем: 300-350кг 0.00 кг.

Как исправить:

2. Вкладка Значение.
3. Сотрите всё в поле «Текст до значения» → Применить → ОК.

Почему на схеме отображается «?.?? кг»?

Знак ?.?? означает недостоверный признак качества сигнала (например, значение вышло за пределы выбранной шкалы или не запущен опрос).

  • • Проверьте, что у всех расчетов выставлена суммарная шкала 0-650 (а не 110-300).
  • • Убедитесь, что у входных значений включена Имитация → Шум, а у команд — Опрос выхода → Значение до опроса.

Метод быстрой самопроверки перед сдачей

В режиме исполнения переведите все 5 слайдеров процентов в 0.00:

• Тупиковые узлы (4, 6, 8, 9, 11) обязаны стать 0.00 кг и окраситься в синий цвет.
• Сквозные узлы (3, 5, 7, 10, 12) обязаны показывать одно и то же число (равное сумме Блока 1 и Блока 2). Если хоть один отличается — в формуле вычитания перепутан источник!
